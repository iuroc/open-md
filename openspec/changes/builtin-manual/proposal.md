# Proposal

## Why

OpenMD 的用户第一次右键打开 Markdown 时，可能完全没有写过 Markdown：他们看到的是排版后的正文，不知道源码里的符号是什么意思，也不知道 OpenMD 的源码 / 双视图能用来对照学习。当前应用没有任何内置的入门内容，用户只能离开应用去搜索教程。

把一本简短的中文使用手册随 exe 发布，可以让新用户在阅读页里直接打开，离线可用；手册本身用 Markdown 写成，也顺带演示了标题、列表、代码、链接等写法。

## What Changes

- 新增内嵌的多章节中文 Markdown 手册，内容原创，面向零基础读者。
- 在阅读页「信息与设置 → 关于」增加「打开使用手册」链接，在新标签页打开手册首页。
- 手册在打开文档时按内容指纹生成到本地缓存，之后复用；**不修改**安装 / 管理对话框、安装流程和右键菜单。
- 手册使用现有渲染管线，具备文件树、大纲、源码 / 双视图、打印和主题切换。
- 每章末尾提供外部「延伸阅读」链接；不摘录第三方教程原文，因此不引入新的许可证义务。

## Capabilities

### New Capabilities

- `user-manual`: 内嵌 Markdown 手册的内容范围、生成方式、阅读页入口，以及生成不可用时的降级行为。

### Modified Capabilities

无。

## Impact

- 新增 `internal/manual`：嵌入章节、计算内容指纹、生成与复用手册站点。
- `internal/app/run.go`：打开文档前确保手册可用。
- `internal/render`：站点选项、页面数据、`docpage.html` / `page.html`、`reader.css` 和缓存清单。
- 新增测试；不改变文档渲染、文件树、大纲、主题和安装器行为。
