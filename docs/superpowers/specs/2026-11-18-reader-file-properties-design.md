# OpenMD 阅读器文件属性面板设计

## 背景

阅读器目前能切换文档、显示标题和大纲，但用户看不到当前文档的完整真实路径。排查问题、复制路径、确认打开的是哪个文件时，只能回到资源管理器或命令行。

现有面板由顶栏齿轮按钮打开，包含配色和“关于 OpenMD”，但没有文件信息。用户希望把文件完整路径放进这个面板，并把齿轮换成更中性的圆圈 + i 信息图标。

## 目标

- 在现有面板顶部显示当前文档的完整绝对路径。
- 同时显示当前文档所在目录，目录模式、单文件模式和链接文档模式都适用。
- 切换文档时，路径和目录实时更新。
- 提供“复制路径”操作，方便直接粘贴到资源管理器、终端或聊天工具。
- 将齿轮图标替换为圆圈 + i，面板标题改为“信息与设置”。
- 保持现有配色、作者、版本、构建时间和发布页内容不变。

## 非目标

- 不新建第二个属性面板或第二个顶栏入口。
- 不解析符号链接；这里的“真实路径”指绝对路径（`filepath.Abs` + `filepath.Clean`），不是 symlink 的最终目标。
- 不增加“在资源管理器中打开”“在编辑器中打开”等额外操作。
- 不改变 Markdown 渲染、目录扫描或链接打开方式。

## 方案

### 采用：扩展现有面板

顶栏仍只有一个信息入口。面板从上到下分为：

1. **文件**：当前文档绝对路径、所在目录、复制路径按钮。
2. **配色**：现有四套主题。
3. **关于 OpenMD**：作者、版本、构建时间、发布页。

优点：入口不增加，符合阅读器“只保留阅读相关控件”的方向；文件信息和设置/关于共用一个面板，层级简单。

### 未采用：独立属性面板

单独增加一个属性按钮或侧栏入口。文件属性更显眼，但会多一个顶栏图标和一套面板样式，和当前“顶栏只留侧栏、全宽、信息”三组控件的设计冲突。

### 未采用：放在页面标题或正文顶部

路径会长期占据阅读区域，长路径还会挤压标题；也不方便随文档切换统一管理。

## 设计细节

### 数据

- `Document` 增加 `Dir string`，表示文档所在目录。
- 单文件模式在 `BuildFilePage` 中把传入路径规范为绝对路径；目录模式和链接文档路径本来已是绝对路径。
- 每个 `.doc-section` 输出 `data-path` 和 `data-dir`，供切换文档时读取。
- `pageData` 增加 `ActivePath` 和 `ActiveDir`，用于首屏渲染。

### 面板结构

```text
┌ 信息与设置 ───────────────┐
│ 文件                       │
│ 当前文档                   │
│ C:\Users\...\docs\a.md    │
│ [复制路径]                 │
│ 所在目录                   │
│ C:\Users\...\docs         │
│                            │
│ 配色                       │
│ 海盐蓝  松石  紫藤  石墨    │
│                            │
│ 关于 OpenMD                │
│ 作者 / 版本 / 构建时间      │
└────────────────────────────┘
```

路径使用等宽字体、`overflow-wrap: anywhere`、可选择文本，避免长路径撑破面板。

### 切换文档

`reader.js` 的 `showDoc` 在更新标题和大纲后，读取当前 section 的 `data-path` / `data-dir`，更新面板中的两个 `dd` 元素。首屏由 Go 模板直接输出活动文档路径，避免闪烁。

### 复制路径

点击“复制路径”复制当前文档路径：

1. 优先 `navigator.clipboard.writeText(path)`。
2. 失败时创建临时 `textarea`，选中后 `document.execCommand("copy")`。
3. 成功后按钮短暂显示“已复制”，失败显示“复制失败”。

### 图标

- 使用 20×20 SVG：描边圆圈 + 小写 i（圆点 + 竖线）。
- 按钮仍为 34×34、8px 圆角，和全宽按钮一致。
- `aria-label` / `title` 改为“信息与设置”。
- 面板 `role="dialog"` 的 `aria-label` 和标题同步改为“信息与设置”。

### 可访问性

- 路径文本可被屏幕阅读器读取；`dd` 不设置 `aria-hidden`。
- 复制按钮有明确的 `aria-label`，复制结果用 `aria-live="polite"` 的状态文本反馈。
- 面板打开/关闭沿用现有逻辑，不改变焦点管理范围。

## 风险与取舍

- **路径隐私**：完整路径可能包含用户名和目录结构，截图时会暴露。用户明确要求显示，接受。
- **路径过长**：等宽 + 任意断行 + 面板滚动，保证不撑破布局。
- **剪贴板在 `file://` 下可能受限**：优先 Clipboard API，失败回退 `execCommand`，再失败显示提示。
- **面板内容变多**：文件信息放在顶部，配色和关于仍可滚动访问；面板最大高度沿用现有 `max-height`。

## 验收

- 单文件、目录、链接文档三种模式都能看到当前文档绝对路径和所在目录。
- 切换文档后路径立即更新。
- 复制路径在当前浏览器可用。
- 顶栏图标为圆圈 + i，点击打开“信息与设置”。
- 现有配色、作者、版本、构建时间、发布页行为不回归。
