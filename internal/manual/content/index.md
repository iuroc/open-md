# OpenMD 使用手册

这是一本写给零基础读者的 Markdown 入门手册。你不需要安装别的软件，也不需要联网：手册随 OpenMD 一起发布，打开就能读。

## 这本手册适合谁

如果你第一次右键打开 `.md` 文件，看到排版后的正文却不知道源码里的 `#`、`-`、`**` 是什么意思，这本手册就是为你准备的。建议按顺序读，每章末尾都有可以照着写的小例子。

## 怎么读更有效

OpenMD 顶栏可以切换三种视图：

- **阅读**：只看排版后的正文，适合正常阅读。
- **源码**：看原始 Markdown，适合对照符号和效果。
- **双视图**：左侧源码、右侧正文，最适合边看边学。

读每一章时，先看正文里的例子，再切到源码视图看看它原本长什么样。你也可以打开自己的文件，在双视图里一边改字一边观察效果。
