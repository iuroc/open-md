# 第 2 章：标题、段落与换行

标题让文档有层次，段落决定文字怎么分组。这两件事看起来简单，却是排版问题出现最多的地方。

## 你会学到

- 用 `#` 到 `######` 表示六级标题。
- 为什么一篇文档通常只有一个一级标题。
- 空行、软换行和硬换行的区别。

## 基本写法

标题由 1 到 6 个 `#` 加一个空格组成，`#` 越少级别越高：

```markdown
# 一级标题

## 二级标题

### 三级标题

#### 四级标题
```

段落之间用空行分隔。一个段落内部的单个换行通常会被合并成空格，所以下面的写法仍然是一段：

```markdown
第一行
第二行仍然属于同一段
```

如果确实要换行，可以在行尾留两个空格，或者在行尾加一个反斜杠：

```markdown
第一行末尾有两个空格  
第二行另起一行。

也可以用反斜杠：\
这样也能换行。
```

## 在 OpenMD 里怎么看

OpenMD 用标题生成侧栏大纲：你写几个标题，大纲里就有几项。文档标题默认取第一个一级标题，所以开头最好只放一个 `#` 标题。

从大纲点击某一节时，阅读区会滚动到对应标题；双视图和源码视图也会定位到同一节。标题层级不要跳级，例如从一级直接到三级，大纲看起来会不自然。

## 常见错误

- `#标题` 中间没有空格：不会变成标题。
- 一篇文档写了多个一级标题：大纲和文档标题都会变得混乱。
- 以为按一次回车就能分段：需要空一行。
- 行尾空格被编辑器自动删掉：硬换行失效，可以改用反斜杠。
- 把 `---` 紧贴在文字下面：它可能被当成标题下划线，而不是分隔线。
