# 第 1 章：从零开始

Markdown 是一种用普通文本写文档的格式：你在文字里加入少量符号，阅读器就把它排成标题、列表、链接和代码块。文件本身仍然是纯文本，用任何编辑器都能打开。

## 你会学到

- Markdown 和 Word、笔记软件的区别。
- 在 OpenMD 里切换阅读、源码、双视图。
- 写出第一篇带标题和段落的文档。

## 基本写法

最简单的 Markdown 文档只需要标题和正文。标题用 `#` 开头，正文直接写，段落之间空一行：

```markdown
# 我的第一篇笔记

这是正文。Markdown 用符号表示格式，阅读时看到的是排版后的结果。

这是第二段。段落之间要空一行。
```

把上面的内容保存为 `note.md`，用 OpenMD 打开，你会看到一个标题和两段正文。

## 在 OpenMD 里怎么看

顶栏的阅读模式菜单提供三种选择：

- **阅读**：只看到排版结果。
- **源码**：看到 `# 我的第一篇笔记` 这样的原始文字。
- **双视图**：左边源码、右边正文，两边同步滚动。

学习新语法时，建议用双视图：在左边找到符号，在右边确认效果。窗口宽度不足 900px 时，双视图会自动回到阅读视图，放大窗口即可恢复。

## 常见错误

- 把 Markdown 当成 Word：这里没有工具栏，格式靠符号表达。
- 段落之间没有空行：两段会粘成一段。
- 在中文输入法下输入了全角的 `＃` 或 `－`：Markdown 只认半角符号。
- 以为改了文件就会自动刷新：保存后重新打开页面即可看到新内容。
