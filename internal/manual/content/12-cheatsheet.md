# 速查表

写文档时不必背下所有语法，把这一页放在手边即可。

## 你会学到

- 最常用 Markdown 语法的写法。
- 每种写法对应的效果。
- 遇到不确定的符号时快速对照。

## 基本写法

| 想要 | 写法 | 效果 |
| --- | --- | --- |
| 一级标题 | `# 标题` | 文档大标题 |
| 二级标题 | `## 标题` | 章节标题 |
| 粗体 | `**文字**` | **文字** |
| 斜体 | `*文字*` | *文字* |
| 删除线 | `~~文字~~` | ~~文字~~ |
| 行内代码 | `` `code` `` | `code` |
| 无序列表 | `- 项目` | 圆点列表 |
| 有序列表 | `1. 项目` | 编号列表 |
| 任务列表 | `- [ ] 项目` | 复选框 |
| 链接 | `[文字](地址)` | 可点击链接 |
| 图片 | `![说明](路径)` | 图片 |
| 引用 | `> 文字` | 引用块 |
| 代码块 | 三个反引号包住 | 高亮代码 |
| 表格 | 竖线分隔 | 表格 |
| 分隔线 | `---` | 水平线 |

一个最小的组合示例：

```markdown
# 标题

- [ ] 待办事项

> 一句提示。

| 名称 | 说明 |
| --- | --- |
| A | 第一项 |
```

## 常见错误

- 只看速查表不动手：真正写一次比读十遍记得牢。
- 全角符号和半角符号混用：`＃`、`｜`、`＊` 都不会被识别。
- 忘记留空行：标题、列表、表格和代码块前后通常需要空行。
- 把表格分隔行漏掉：表格会变成普通段落。
- 代码围栏没有闭合：后面的正文会变成长代码。
